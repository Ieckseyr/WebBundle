# 单独挂载网页端、冷查看、完整 NBT 与离线修改

> 状态：v1.3（按“离线查看属于单独挂载网页端”修正）
> 上游：[00 v1 范围](00-v1范围与运行时探针.md) / [01 总体架构](01-总体架构与设计决策.md) / [02 插件层](02-插件层与链入API.md) / [03 存储](03-数据模型与v1存储.md) / [04 网页层](04-网页层与HTTP契约.md)
> 本文定义 `webbundle-web`：单独挂载的网页端。它负责 BDS 离线查看；**不部署它，就没有离线查看**。

---

## 1. 边界

- **形态 A（插件内置网页）**：qjs `HttpServer`，只在 BDS 运行时可用；BDS 停止后消失。
- **形态 B（单独挂载网页端）**：`webbundle-web`，独立进程/独立数据库；插件推送数据；BDS 停止后仍可看最后一次备份。
- **没有部署/启动 `webbundle-web`：BDS 停止后没有任何网页可用**。不提供内置兜底、不偷偷启动常驻服务。
- `webbundle-web` 可以部署在本机，也可以部署在另一台机器；它是独立组件，不是插件进程的一部分。
- 它**不直接读写世界存档**；所有游戏内写入仍由 qjs 插件执行。

---

## 2. 组件与部署

| 组件 | 职责 | 端口 |
|---|---|---|
| WebBundle qjs 插件 | 采集、影子状态、完整 NBT、在线/离线写入、命令、推送/轮询 | 内置 Web 19380（形态 A） |
| `webbundle-web` | 网页、自有数据库、冷查看、动作队列 | 8080（示例，反向代理后） |
| 浏览器 | 查看/编辑/提交动作 | — |

`webbundle-web` 的数据库可以是 SQLite（单机）、RocksDB（高性能单机）或 MongoDB（多机，v2）；v1 默认 SQLite/RocksDB，自行选择。

部署要求：

- 独立进程/容器，开机自启；
- 有自己的磁盘与备份；
- 通过 HTTPS 反向代理暴露；
- 与插件之间用 `pushToken` 认证；与浏览器之间用管理员账号密码 + 会话 Cookie。

## 3. 冷查看

### 3.1 前提

冷查看不是“自动可用”的：

1. `webbundle-web` 已部署并运行；
2. 插件已把最后一次备份/事件推送到它；
3. 浏览器能访问它。

缺任何一个，BDS 停止后都看不到数据。

### 3.2 展示

- `server.online=false`、`dataAsOf`、`mode=cold`。
- 最后一次备份/分钟备份/历史详情/完整 NBT/物品去向/审计。
- 写操作进入 `queued_offline`；开服后插件拉取执行。
- 不伪造实时：没有新数据就显示最后时间。

### 3.3 数据来源

- 插件在运行期间推送备份/增量/事件/NBT/玩家元数据；
- `webbundle-web` 存自己的库；
- 插件停止后，库就是最后状态；
- 插件恢复后按 `lastAckSeq` 续传，补齐断档。

## 4. 完整 NBT

### 4.1 推送

- 小 NBT 内联在 `ItemStack.nbt`；
- 大 NBT 走 `nbtRef`，单独推送 `nbt` 对象（按哈希去重）；
- 单物品/单备份有上限：默认 512KB/8MB；超限 `nbtOmitted=true`，不静默截断。

### 4.2 查看

- 物品详情返回 `nbt`/`nbtRef`/`nbtSize`/`nbtOmitted`；
- 大 NBT 通过 `/api/v1/nbt/:ref` 取；
- 冷查看同样可看已推送的 NBT；未推送的 NBT 需要 BDS 启动后刷新。

### 4.3 编辑

- 网页提交 SNBT；`webbundle-web` 只做粗检/转发；
- 插件用 `NBT.parseSNBT` 解析、校验、写回在线/离线；
- 重新读取校验；pre-edit 备份 + 审计；
- BDS 停止时编辑入队，开服后执行。

## 5. 在线/离线背包修改

| 目标 | 路径 |
|---|---|
| 在线 | `Player.getInventory()/getArmor()/getOffHand()/getEnderChest()` |
| 离线（BDS 运行中） | `data.xuid2uuid` → `mc.getPlayerNbt` → 改 `Inventory/Armor/Offhand/EnderChestInventory` → `mc.setPlayerNbtTags` |
| BDS 关闭 | `webbundle-web` 队列 `queued_offline`；开服后插件执行 |

约束：

- 写入前后检查玩家是否在线；在线改走在线路径，避免离线 NBT 覆盖在线状态。
- 用 `setPlayerNbtTags` 只覆盖背包相关标签，不整份覆盖玩家 NBT。
- 失败不重试覆盖；pre-edit 备份可回滚。
- 离线修改需 `inventory.write` + 确认；默认 admin。
- 玩家下次进服生效，页面提示。
- **不在 `webbundle-web` 直接编辑世界存档**；直接编辑是另一个项目，v1 不做。

## 6. 插件 ↔ webbundle-web 契约

### 6.1 推送（插件 → webbundle-web）

```text
POST /push/v1/register   { serverId, name, version, lastAckSeq }
POST /push/v1/actions    { items: [ActionDescriptor] }
POST /push/v1/player     { xuid, uuid, name, online, lastSeen }
POST /push/v1/snapshot   { items: [InventorySnapshot] }
POST /push/v1/delta      { items: [InventoryDelta] }
POST /push/v1/flow       { items: [FlowEvent] }
POST /push/v1/audit      { items: [AuditRecord] }
POST /push/v1/heartbeat  { ts, queueDepth, lastAckSeq }
```

- 批量 ≤200 条或 64KB；失败重试 + 插件本地 spool。
- 幂等：`id`/`eventId`。
- 返回 `lastAckSeq`。

### 6.2 动作（插件 ↔ webbundle-web）

```text
GET  /push/v1/actions/pending?serverId=&limit=8
POST /push/v1/actions/result  { taskId, state, result, error }
```

- 插件每 1 秒轮询；有 WS 时 v2 升级。
- 动作由网页写入 `webbundle-web`；插件拉取后世界线程执行。
- BDS 未运行：动作停留 `queued_offline`；插件启动后拉取。

### 6.3 健康

- 插件启动时 `GET /push/v1/health`；失败进入 spool。
- `webbundle-web` 显示 `server.online` 由心跳/最后推送时间推断。

## 7. 安全

- `pushToken` 与浏览器账号分离；只允许 `/push/v1/*` 使用机器令牌。
- 强制 HTTPS；插件校验证书（`allowInsecure` 仅本机调试）。
- 请求带 `X-WebBundle-Server`/`X-WebBundle-Seq`；服务端校验 serverId 与令牌绑定。
- 重放保护：`ts`/`lastAckSeq` 单调。
- 浏览器密码只存 PBKDF2-SHA256 哈希 + 盐；没有默认账号，首次设置只允许本机。
- 离线修改：权限/确认/pre-edit 备份/审计；冷查看也鉴权。
- 大 NBT 按权限显示；不写日志。

## 8. 故障矩阵

| 故障 | 形态 A | 形态 B | 数据 |
|---|---|---|---|
| BDS 停止 | 网页不可用 | 冷查看 | 最后备份 |
| `webbundle-web` 未部署 | 正常 | **无离线查看** | 仅本地 |
| `webbundle-web` 停止 | 正常 | 网页不可用 | 插件 spool；重启补写 |
| 插件崩溃 | 网页不可用 | 最后数据 | 最后分钟备份 |
| 推送失败 | 正常 | 数据滞后 | spool 重试 |
| 离线 NBT 写入失败 | — | 任务失败 | pre-edit 备份回滚 |
| 玩家在离线写入期间进服 | — | 任务失败/转在线 | 不覆盖在线 |

## 9. 验收

- [ ] 未部署 `webbundle-web` 时，BDS 停止后确认没有任何网页可用。
- [ ] 部署 `webbundle-web` 后，BDS 停止仍能看最后备份/备份/NBT/物品去向。
- [ ] 插件推送断档后恢复，按 `lastAckSeq` 续传，不重复入账。
- [ ] 完整 NBT 小内联/大 ref；冷查看可看已推送 NBT。
- [ ] 在线/离线（BDS 开）背包/NBT 可改；下次进服生效。
- [ ] BDS 关闭时离线修改入队，开服后执行，结果可查。
- [ ] 离线修改有 pre-edit 备份、权限、确认、审计、冲突检查。
- [ ] 不在 `webbundle-web` 直接改世界存档。
