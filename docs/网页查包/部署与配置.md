## 1. 两种形态

```text
形态 A：内置网页
  BDS + WebBundle 插件 + LSE HttpServer
  http://服务器地址:19380/

形态 B：独立网页端
  BDS ──HTTP 推送──▶ webbundle-web（Node.js）
  http://服务器地址:8080/
```

- 内置网页只在 BDS 运行时可用。
- 独立网页端在 BDS 停止后仍可查看最后一次同步的数据。
- 独立端的写入动作会排队，等待 BDS 恢复后执行。
- 两边都使用普通 HTTP。

## 2. 安装与升级

1. 将整个目录放到：

   ```text
   plugins/WebBundle/
   ```

2. 启动 BDS。
3. 控制台出现：

   ```text
   [WebBundle] 内置网页监听 0.0.0.0:19380
   ```

4. 打开：

   ```text
   http://服务器IP:19380/
   ```

5. 首次创建管理员时填写 `config.json` 的 `web.token`。
6. 需要 BDS 停止后仍能查看时，再部署独立端：

   ```bash
   node plugins/WebBundle/standalone/server.js
   ```

升级时保留：

```text
plugins/WebBundle/data/config.json
plugins/WebBundle/data/db/
plugins/WebBundle/standalone/config.json
plugins/WebBundle/standalone/data/store.json
```

## 3. 鉴权

- 内置端管理员账号
- 独立端管理员账号
- Cookie 会话
- Bearer Token API
- 首次设置必须输入 BDS `web.token`
- 首次设置：`web.token`
- 不接受 `external.token` / `pushToken`

Cookie：

```text
HttpOnly
SameSite=Strict
Path=/
Max-Age=43200
```

纯 HTTP 不设置 `Secure`。反向代理传入：

```text
X-Forwarded-Proto: https
```

才设置 `Secure`。

### 3.1 首次创建管理员

首次创建管理员必须输入 BDS：

```text
plugins/WebBundle/data/config.json
```

中的：

```json
"web": {
  "token": "自动生成或手动设置的管理员 Token"
}
```

内置端和独立端都只接受这一个 `web.token`。

不接受：

- `external.token`
- 独立端 `pushToken`

步骤：

1. 打开 BDS 的 `config.json`，复制 `web.token`。
2. 打开内置端 `/` 或独立端 `/setup`。
3. 在「Web Token」输入框填入该值。
4. 创建管理员。

注意事项：

- 本机访问也不能跳过 Web Token。
- 独立端会把输入的 Token 发送到 `bdsUrl/api/v1/meta` 验证，因此独立端首次设置要求 BDS 在线。
- Token 通过 HTTP 明文传输，公网建议配合 HTTPS 反向代理。
- `web.token` 是长期 API Token，不是一次性初始化令牌，不要泄露。
- 账号已存在后首次设置接口返回 409。

手机 HTTP 非安全上下文没有 `crypto.subtle` 时：

1. WebCrypto PBKDF2
2. 纯 JS `web/pbkdf2.js`
3. 两者都不可用才报错

### 静态资源白名单

内置网页只加载：

```js
["index.html", "app.js", "app.css", "style.css", "pbkdf2.js", "textures/items-map.json"]
```

## 7. 备份模型

单份快照：

```text
id
xuid / name / uuid
seq
ts
reason
batchId / batchAt / batchReason
itemCount
containerCounts
inventory / armor / offhand / ender
nbtRef
```

批次规则：

| 场景 | 批次 |
| --- | --- |
| 分钟备份 | 同一分钟所有在线玩家共享 |
| 手动全服备份 | 所有在线玩家共享 |
| 关服备份 | 所有在线玩家共享 |
| 单玩家手动备份 | 独立 |
| 进服/退服 | 独立 |
| 离线快照 | 独立 |

全服备份页按批次显示文件夹。展开后显示：

- 玩家名 / XUID
- 备份时间
- 物品总数
- 背包 / 装备 / 副手 / 末影箱数量
- 查看
- 还原

旧快照没有 `batchId` 时，分钟备份按分钟分组，其他按理由 + 5 秒窗口兼容分组。

快照查看模式只读。需要修改时先还原，再编辑实时背包。

## 8. 外网部署

- 默认监听 `0.0.0.0`
- 端口：`19380`、`8080`
- 公网需要放行防火墙/安全组/NAT
- HTTP 明文会暴露登录密码和 Cookie
- 公网建议在反向代理层启用 HTTPS
- 反向代理需保留 `Host` 和 `X-Forwarded-Proto`
- 同服务器时内部地址用回环
- 分开部署时修改 `external.url` / `external.publicUrl`

## 10. 排查

### 网页打不开

- 检查 BDS 日志是否出现 `内置网页监听`
- 检查端口 `19380`
- 检查防火墙/安全组

### 独立端打不开

- 检查 `plugins/WebBundle/standalone/config.json` 的 `listen`
- 检查 `bdsUrl`
- 检查 `pushToken` 是否一致
- 检查 `logs/webbundle-web.log`

### 登录提示 PBKDF2 后备脚本未加载

检查：

```text
GET /pbkdf2.js?v=2
```

必须返回 JavaScript，不能返回 `index.html`。

### 备份文件夹只有一个玩家

- 单玩家备份/进服/退服/离线快照本来就是单玩家批次
- 分钟备份和全服手动备份才会包含多个在线玩家

### 快照不能编辑

设计为只读。先还原，再编辑实时背包。
